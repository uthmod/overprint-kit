疊印分色

把一張只用色盤顏色畫的圖，拆成四塊印版，一支油墨一塊，再做一張印刷模擬，送印前先看效果。圖片只在您的瀏覽器裡處理，不會上傳到任何地方。

    畫圖小提醒

    • 整張圖只用色盤裡的 16 種顏色。用 Illustrator、Photoshop 或 InDesign 的話，匯入信裡附的 Adobe 色票就好。
    • 用平塗，每塊顏色填滿、邊緣清楚；漸層、陰影和半透明會被併成最接近的一種顏色。
    • 不印油墨的地方留白。存成 PNG，JPG 會讓色塊邊緣出現雜色。

    這個頁面和疊印工具包裡 Claude Code 版的「分色」用同一套算法；我們用五張範例圖比對過，兩邊分出的印版每一點都相同。
