疊印分色

把一張只用色盤顏色畫的圖，拆成四塊印版，一支油墨一塊，再做一張印刷模擬，送印前先看效果。圖片只在您的瀏覽器裡處理，不會上傳到任何地方。

1您的圖

PNG、JPG 或 WebP，也可以直接把圖拖到這個頁面上。透明的地方當作紙色；太大的圖會自動縮小。

    3圖的類型

    4網點（選用）

    某個顏色要印得比較淡，但它和旁邊的顏色會分到同一支墨時（例如臉和頭髮），可以把它印成網點。按下面的按鈕，再點一下圖上的那個顏色。圖上和它同色的地方都會一起印成網點（範例裡，卡片上和臉同色的愛心也是）。

      網點是 80 lpi，照這個寬度計算；印得比這個寬或窄，網點會跟著變粗或變細。

      印刷模擬

      分色中…

      按住圖片拖曳就能移動，兩張圖會一起動。印刷模擬是印版的實際大小。

      紅線是分色時描出的邊界。線圍起來的每一塊，先整塊配一個印刷色，所以平塗的地方不會出現雜點；只有明顯不同的點（例如沒有邊線的陰影）才保留自己的顏色。紅線上的點各自找最接近的顏色，細線因此留得下來。

      四塊印版

      下載

      印版是原圖的 3 倍大。

      壓縮檔裡有四塊印版（黑色的地方上墨）和一張印刷模擬，都是 PNG。

      畫圖小提醒

      • 整張圖只用色盤裡的 16 種顏色。用 Illustrator、Photoshop 或 InDesign 的話，匯入信裡附的 Adobe 色票就好。
      • 用平塗，每塊顏色填滿、邊緣清楚；漸層、陰影和半透明會被併成最接近的一種顏色。
      • 不印油墨的地方留白。存成 PNG，JPG 會讓色塊邊緣出現雜色。
      • 圖的大小：印版是圖的 3 倍，照印刷尺寸算，圖有 200 dpi，印版就有 600 dpi；400 dpi 最理想，曲線最銳利。這個頁面最多處理大約 180 萬像素的圖，更大的會先縮小。
      • 淺色的細線和小點至少畫 2 個像素寬，更細的會被當成雜點去掉；深色細線會自動補回來。

      這個頁面和疊印工具包裡 Claude Code 版的「分色」用同一套算法；我們用五張範例圖比對過，兩邊分出的印版每一點都相同。
